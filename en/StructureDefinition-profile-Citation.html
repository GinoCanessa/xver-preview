Resource Profile: Profile_R5_Citation_R4

Official URL: http://hl7.org/fhir/5.0/StructureDefinition/profile-Citation Version: 0.1.0
Standards status: Trial-use Active as of 2026-03-04 Maturity Level: 0 Computable Name: Profile_R5_Citation_R4

This cross-version profile allows R5 Citation content to be represented via FHIR R4 Basic resources.

Usages:

Show 3 more, R5: Citation for this report (new), R5: Link to results generated during the study (new) and R5: Supporting literature (new)
