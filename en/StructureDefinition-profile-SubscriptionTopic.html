Resource Profile: Profile_R5_SubscriptionTopic_R4

Official URL: http://hl7.org/fhir/5.0/StructureDefinition/profile-SubscriptionTopic Version: 0.1.0
Standards status: Trial-use Active as of 2026-03-04 Maturity Level: 0 Computable Name: Profile_R5_SubscriptionTopic_R4

This cross-version profile allows R5 SubscriptionTopic content to be represented via FHIR R4 Basic resources.

Usages:

  • Refer to this Profile: R5: Instantiates FHIR protocol or definition (new), R5: Reference to the subscription topic being subscribed to (new), R5: Reference to the SubscriptionTopic this notification relates to (new), R5: Based on FHIR protocol or definition (new) and R5: What event (new)
